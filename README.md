# Student Course Registration System

## Project Title
Student Course Registration System

## Technologies Used
- Python 3 (Tkinter for GUI)
- MySQL (mysql-connector-python)

## Features Implemented
- [ ] Add / View / Update / Delete / Search Students
- [ ] Add / View / Update / Delete Departments
- [ ] Add / View / Update / Delete Lecturers
- [ ] Add / View / Update / Delete Courses
- [ ] Register a student for a course
- [ ] View a student's registered courses
- [ ] Reports: all students, students by department, students per course, courses per lecturer
- [ ] Database: foreign keys, views, stored procedures, indexes

## How to Run
1. Run `schema.sql` in MySQL to create the database and tables.
2. `pip install mysql-connector-python`
3. Update the password in `database.py`.
4. `python main.py`
